Drop your TTF font file here.

Recommended gaming fonts (all free / OFL licensed):
  - Fredoka One  → https://fonts.google.com/specimen/Fredoka+One   (casual/friendly)
  - Bangers      → https://fonts.google.com/specimen/Bangers        (bold/action)
  - Righteous    → https://fonts.google.com/specimen/Righteous      (clean/modern)

Steps after dropping the TTF in this folder:
  1. Let Unity import it (small spinner in bottom-right)
  2. Right-click the TTF → Create → TextMeshPro → Font Asset
  3. Select the UIManager GameObject in the scene
  4. Drag the created .asset file into the "Game Font" field on UIManager
  => All HUD texts will switch to the new font automatically on Play
